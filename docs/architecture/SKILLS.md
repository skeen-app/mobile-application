# Claude Code Skills - skeen

## Custom Commands
- `skeen-init`: Initializes Clean Architecture folder structure and fetches dependencies.
- `skeen-check`: Runs a full quality pass (format, analyze, tests).
- `skeen-gen`: Triggers build_runner for code generation (Riverpod, Freezed, etc.).
- `skeen-build-apk`: Automated pipeline for building the release APK.
